# AgriMitra Containerization & Docker Configurations

This directory will store Dockerfiles, docker-compose configurations, and container orchestration scripts for local development and deployment.

## Planned Containers

- `backend`: FastAPI server container
- `frontend`: React app web server / build container
- `db`: PostgreSQL database container

## Current Status

- **Phase 0:** Directory initialized. Dockerfiles and compose setups will be configured in upcoming implementation phases.
